# Nodes

A small strategy game of connections: capture, grow, and take the board.

Play at **https://MuneerFergiani.github.io/Nodes/**.

This repository contains the published website in `site/`. Tutorial, single-player and settings are available; online multiplayer is coming soon.

GitHub Actions publishes `site/` to Pages when `main` changes. The game is developed separately using TypeScript and Pixi.js; build it with `npm run build:pages` and replace the website files for a new release. Server credentials and backend files do not belong in this repository.
